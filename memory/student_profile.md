# 学生画像

> **文件用途**：记录学生的基本信息、学习偏好与情绪模式，是所有老师了解学生的"第一份档案"。
> **更新规则**：在 `/上课` 时被读取（优先级 1）；在 `/下课` 时由系统根据本节课的观察酌情更新偏好与情绪相关字段。基本信息字段一般由学生主动告知后填写。
> **共享范围**：所有老师共享读取，互动时应尊重此处记录的偏好。
