# 苏格拉底·七 · AI 学习助手

> **一套基于苏格拉底教学法的多老师 AI 家教系统**——通过提问引导学生自主发现知识，而不是直接灌输答案。

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Claude%20Code%20%7C%20Trae%20%7C%20Qoder-orange.svg)](#环境要求)

## 这是什么

"苏格拉底·七"是一套运行在 Agentic Engineering 工具（Claude Code / Trae / Qoder 等）上的 AI 学习系统。它不是又一个"AI 帮你查答案"的工具——它的核心规则只有一条：

> **不给你答案。只问你问题。**

苏格拉底两千多年前就靠这招，把雅典的年轻人问得怀疑人生又欲罢不能。他不告诉任何人"答案是什么"，他只问问题，一层一层地问，问到你自己在脑子里把逻辑链条拼起来。

那个"拼起来"的瞬间，才是真正理解发生的瞬间。

教育心理学研究显示，学生在"被引导自己发现答案"时的大脑活跃度，是被动接收答案时的 **3 倍以上**。"听懂"和"想通"，是两件完全不同的事。

## 核心特性

### 1. 苏格拉底式提问
每个问题都在你现有认知的边缘轻轻推一下，推到你自己迈过去。迈过去的那一步，是你的，谁也拿不走。系统内置四层提问策略（脚手架 → 探测 → 挑战 → 连接）和三级提示机制，确保你被卡住时永远有下一级线索。

### 2. 三位虚拟老师，风格迥异

| 老师 | 性格 | 教学特长 | 标志性台词 |
|------|------|----------|-----------|
| **木之本樱** | 活泼开朗、元气满满 | 生活化类比、脚手架拆解 | "一定没问题的！" |
| **三笠** | 冷面严师、话少精准 | 逻辑链断裂点定位、挑战式提问 | "你的逻辑在第二步就断了。" |
| **芙莉莲** | 千年魔法师、慢悠悠 | 概念边界拆解、极致耐心 | "嗯…我们先不谈正义。先告诉我，你说的'强者'，是指什么？" |

一个问题卡住了？换个老师，换个角度，路就通了。

### 3. 长期记忆系统
不是每次"重新认识你"，而是"接着上次的进度继续"。
- 芙莉莲记得你上个月在极限定义上卡过三次
- 三笠知道你最近推理速度变快了
- 木之本樱会继续用上次给你起的昵称

每次上课前自动加载学习进度、薄弱点、复习计划、师生关系记忆；下课时全部落盘更新。

### 4. 教材锚定防幻觉
所有教学内容以 `textbooks/` 中的教材为唯一事实来源。超出教材的延伸必须明确标注（`💡 这超出了教材范围…`），涉及数学计算必须逐步展示推理过程并自我验证。它不会一本正经地胡说八道——它是一个会坦然承认"这个超出教材范围了"的 AI。

### 5. 课后群聊复盘
每节课结束后，三位老师会在"微信群"里讨论你今天的表现——谁开口、夸什么、补什么细节，都基于本节课真实发生的授课记录。你输入 `/群聊` 就能看到，还能回复，老师会接着回你。

学习这件事，从"一个人的任务"变成了"一群人的陪伴"。

### 6. 间隔重复复习
基于艾宾浩斯遗忘曲线，自动安排复习节点（1天 → 3天 → 7天 → 14天 → 30天）。通过则延长间隔，未通过则缩短并降级掌握状态。复习时同样用苏格拉底式提问检测，而非让你背诵。

### 7. 课间续接
单节课对话轮次过多、上下文窗口将溢出时，系统会主动建议"歇一下脑子"——执行完整课后流程保存进度，在新会话中无缝续接。不算一节新课，不消耗课次编号。

## 快速开始

### 环境要求

- **Agentic Engineering 工具**（任选其一）：
  - [Claude Code](https://docs.anthropic.com/en/docs/claude-code)（推荐，原版开发环境）
  - [Trae](https://www.trae.ai/)
  - [Qoder](https://qoder.com/)
- **AI 模型**：Claude Opus 4.x / Sonnet 4.x（推荐）；GPT-4o / DeepSeek 等亦可（详见 `system/model_adapter.md`）
- **Python 3.10+**（仅在使用 `/转换` 命令转换教材格式时需要）

### 三步上手

#### 1. 克隆项目

```bash
git clone https://github.com/RiveMar/learning-assistant.git
cd learning-assistant
```

#### 2. 放入教材

把你要学的教材放到 `textbooks/` 目录下。支持格式：

| 格式 | 说明 |
|------|------|
| `.md` | **推荐**，AI 可直接读取 |
| `.txt` | 可直接读取 |
| `.epub` / `.mobi` | 用 `/转换` 命令自动转 Markdown |
| `.pdf` | 可读取，建议转为 Markdown 获得最佳效果 |

如果是 PDF/EPUB，先安装依赖再转换：

```bash
pip install -r requirements.txt
# 在对话中输入：/转换 textbooks/你的教材.epub
```

#### 3. 开始学习

在你的 Agentic Engineering 工具中打开项目目录，输入：

```
/上课
```

系统会自动加载教材、生成课程大纲、分配老师，开始你的第一节课。

## 命令一览

| 命令 | 功能 |
|------|------|
| `/上课` | 开始一节新课（可指定老师：`/上课 三笠`） |
| `/下课` | 结束当前课程，自动更新所有记忆文件 + 生成课后群聊 |
| `/切换老师 [名字]` | 课中切换授课老师，无缝衔接 |
| `/复习` | 进入复习模式，检测到期复习任务 |
| `/进度` | 查看学习进度与薄弱知识点 |
| `/群聊` | 查看未读群聊，可选回复老师 |
| `/知识图谱` | 可视化展示各知识点掌握程度 |
| `/转换 [文件路径]` | 将 PDF/EPUB/MOBI 教材转为 Markdown 并拆分章节 |

## 定制你的系统

### 添加新老师

1. 复制 `teachers/_template.md` 为新文件（如 `teachers/新老师.md`）
2. 填写人设档案：基本信息、性格、说话风格、教学风格、鼓励方式
3. 在 `memory/bonds/` 下创建对应的 `新老师_bond.md`（可参考现有老师）
4. 在 `world/group_dynamics.md` 中补充新老师与其他老师的互动规则
5. 开始使用：`/切换老师 新老师`

### 修改世界观

编辑 `world/background.md` 调整故事背景，编辑 `world/group_dynamics.md` 调整三位老师的互动模式（谁和谁会拌嘴、谁总是补刀、谁负责打圆场）。

### 调整教学策略

`system/socratic_method.md` 是教学法的核心——四层提问策略、难度自适应、节奏控制、失败模式自修复规则都在这里。如果你想调整"AI 什么时候该给提示、给多详细的提示"，改这个文件。

## 设计哲学

### 为什么是"不给你答案"？

当所有人都在让 AI 更直接、更"一步到位"的时候，我们偏要让 AI 变"慢"。

AI 给你的是一段逻辑完整的解释，你的大脑只需要说一句"嗯，有道理"——然后这段信息就像阅后即焚，两周后烟消云散。但那些你咬着牙、翻了三本书、跟同学争了一晚上才想通的东西，你可能到现在都记得清清楚楚。

**AI 给你的不是"理解"，是"我已经理解了的错觉"。**

苏格拉底·七的唯一目标，就是把这个"错觉"变成真正的"想通"。

### 为什么是三位老师？

同一个知识点，木之本樱会用超市货架的类比帮你建立直觉，三笠会用一刀切的逻辑链找到你的断裂点，芙莉莲会把概念拆成七八个小步骤让你看清边界。不同的脑子，不同的路径——一个问题卡住了，换个老师，换个角度，路就通了。

### 为什么是异步群聊？

实时群聊会打断学习节奏、消耗 context。课后复盘是"异步"的——上完课再回头看，既有陪伴感，又不干扰主流程。下次打开系统时发现"群里响了"，才有惊喜感。

### 为什么不数值化？

曾对工作日程做过很多"游戏化"尝试——征服世界、升级打怪、商业帝国——最终都沦为无聊的数值游戏。"苏格拉底·七"完全抛弃数值化，它的陪伴感不依赖张牙舞爪的征服欲，而基于温情脉脉的朋友之谊，这反而对学习动力形成了隽永的呵护。

## 已知限制

- **数学公式渲染**：Claude Code for VS Code 的聊天界面不原生渲染 LaTeX，系统通过将含公式的段落写入 `temp/` 临时文件并提供预览链接的方式解决（VS Code 的 Markdown Preview 支持 KaTeX）
- **语音化**：目前仅支持文字对话。理想的语音对话需要更快的模型响应和二次元角色配音版权，预计未来可期
- **模型依赖**：教学效果与所用模型强相关。Claude Opus 4.x 表现最佳； weaker 模型可能出现角色出戏、苏格拉底退化（直接给答案）等问题，系统内置了自动修复机制（详见 `session_protocol.md` §6.5）
